# WorldWise

Welcome to **WorldWise**, a personal project developed as part of the Ultimate React Course. This platform allows you to log details about the countries you have visited, including the date and time of your trip, and any notes you want to remember.

## Features

- **Add Trip Details**: Write details about the countries you have visited and store them in the database.
- **Country Selection**: Add countries by typing their names, selecting them on the map, or enabling access to your current location.
- **Trip Notes**: Include the date, time, and personal notes for each trip.

## Installation

To get a local copy up and running, follow these simple steps:

1. **Clone the repo**

```bash
git clone https://github.com/abdelaleemadel/WorldWise.git
```

2. **Naigate to the project directory**

```bash
cd WorldWise
```

3. **Install dependecies**

```bash
npm install
```

4. **Use your Database**

Use your supabaseUrl and supabaseKey to store cities, each city table should has the following properties {id, cityName, country, emoji, flag, date, notes, position:{lat, lng}}.

5. **Run the application**

```bash
npm run dev
```

## Usage

1. Open your browser and navigate to http://localhost:5173

2. Log in using the fake login system

3. Add details about your trips, including the country, date, time, and notes.

4. View and manage your trip entries
